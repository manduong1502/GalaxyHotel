# 🏨 GALAXY HOTEL & SUITES - Luxury Hotel & Booking Engine

Official repository for **Galaxy Hotel & Suites** — a luxury 5-star hotel web application featuring an interactive dual-mode booking engine (Hourly & Daily bookings), availability calendar, and seamless bilingual support (Vietnamese & English).

![Galaxy Hotel Preview](https://images.unsplash.com/photo-1542314831-068cd1dbfeeb?auto=format&fit=crop&w=1200&q=85)

---

## ✨ Key Features (Tính năng nổi bật)

- 🌐 **Song Ngữ Anh - Việt (Bilingual VI/EN):** Seamless 1-click language switcher without page reload.
- ⏱️ **Đặt Phòng Linh Hoạt Theo Giờ & Theo Ngày (Dual Booking Engine):**
  - **Daily Booking:** Select Check-in/Check-out dates, guest count, and room tiers.
  - **Hourly Booking:** Select stay date, exact check-in hour (e.g. 08:00, 14:00, 20:00), duration (2h, 3h, 4h, 6h), and automated pricing calculator.
- 📅 **Lịch Phòng Còn Trống Trực Quan (Interactive Availability Calendar):** Month matrix highlighting available, partially booked, and locked slots.
- 🛏️ **Danh Mục Hạng Phòng & Bảng Giá Chi Tiết:** Deluxe Double, Superior, Senior Deluxe, Premier Twin, Galaxy Luxury Suite.
- 🍽️ **Nhà Hàng Sky Dining & Tiện Ích 5 Sao:** Technogym Fitness Center, Himalayan Salt Wellness Spa, Rooftop Infinity Pool.
- 🖼️ **Thư Viện Ảnh & Lightbox:** Filterable gallery by categories with high-res zoom.
- 📱 **Mobile First & Bottom Sticky Action Bar:** Optimized for smartphone thumbs (quick call, Zalo chat, and 1-tap book now).
- ⚡ **Tốc Độ & Hiệu Ứng 60fps:** Ken Burns banner zoom, smooth scroll reveals, magnetic button physics, and custom cubic-bezier easing.

## 🛠️ Tech Stack (Công nghệ sử dụng)

- **Frontend:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Custom Luxury Theme + Google Fonts (`Cormorant Garamond`, `Be Vietnam Pro`, `Cinzel`)
- **Icons:** Lucide React
- **Architecture:** Serverless integration with Google Sheets & Google Apps Script API (Roadmap)

## 🚀 Getting Started (Hướng dẫn cài đặt & chạy)

### 1. Clone repository
```bash
git clone https://github.com/manduong1502/GalaxyHotel.git
cd GalaxyHotel
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:3000/` in your browser.

### 4. Build for production
```bash
npm run build
```
